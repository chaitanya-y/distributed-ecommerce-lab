# OrderFlow Lite

OrderFlow Lite is a small full-stack microservices project.

The goal is to practice:

- Next.js frontend development
- Node.js and Express backend services
- REST API design
- PostgreSQL for orders
- MongoDB for products
- RabbitMQ for event-driven architecture
- Async email/notification workers
- Cron-style scheduled jobs
- API gateway patterns
- Elasticsearch for product search
- Request validation
- Rate limiting
- Logging
- Basic testing
- Docker Compose

## Services

- frontend
- api-gateway
- product-service
- order-service
- notification-worker
- scheduler
